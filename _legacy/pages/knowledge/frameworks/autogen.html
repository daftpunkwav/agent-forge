AutoGen：多Agent对话框架

AutoGen 是微软推出的多Agent协作框架，让多个AI Agent通过对话协作完成复杂任务。核心理念：让Agent"聊天"来解决问题。

多Agent协作

AutoGen 的核心创新是Conversation Programming——将Agent之间的交互建模为对话。每个Agent有独立的角色和系统提示，它们通过交换消息来协作完成任务。

想象一个团队：产品经理定义需求、工程师编写代码、测试员验证质量。AutoGen让AI Agent扮演这些角色，通过对话完成工作——就像真实团队一样。

核心洞察：复杂任务通过分解为多个Agent的子任务来解决。Agent之间的对话既是协作机制，也是天然的可审计日志。

核心概念

ConversableAgent

AutoGen的基本构建块。每个Agent是一个对话参与者，可以接收消息、生成回复、调用工具。

GroupChat

多个Agent的对话管理器。它管理对话流程——谁说话、什么时候说话、对话何时结束。

GroupChatManager

控制对话轮次的Agent。它决定下一个由哪个Agent发言，以及何时终止对话。

代码示例

Python · AutoGen 多Agent协作 
import autogen
from autogen import ConversableAgent, GroupChat, GroupChatManager

# 1. 创建AssistantAgent（助手）
assistant = ConversableAgent(
    name="Assistant",
    system_message="你是一个编程助手。帮助用户编写和调试代码。",
    llm_config={"model": "gpt-4o"},
)

# 2. 创建UserProxyAgent（用户代理）
user_proxy = ConversableAgent(
    name="User",
    system_message="你代表用户，负责执行代码和提供反馈。",
    human_input_mode="NEVER",
    code_execution_config={"work_dir": "coding"},
)

# 3. 创建GroupChat
group_chat = GroupChat(
    agents=[user_proxy, assistant],
    messages=[],
    max_round=20,
)

# 4. 创建Manager
manager = GroupChatManager(
    groupchat=group_chat,
    llm_config={"model": "gpt-4o"},
)

# 5. 启动对话
user_proxy.initiate_chat(
    manager,
    message="写一个Python函数来计算斐波那契数列的第n项"
)
# 输出：Assistant和User自动对话，完成编码+测试

协作模式

  • 一对一协作：两个Agent交替对话（如：编码Agent + 审查Agent）
  • 多Agent辩论：多个Agent对同一问题给出不同观点
  • 层级管理：Manager Agent分配子任务给Worker Agent
  • 人类介入：在关键节点引入人类反馈

框架对比

  • vs LangChain：AutoGen专注多Agent对话；LangChain更通用
  • vs CrewAI：AutoGen更底层更灵活；CrewAI更高层更简单

最佳实践

  • 明确的角色：每个Agent的系统提示要清晰定义职责和边界
  • 控制对话轮数：设置max_round防止无限对话
  • 终止条件：定义明确的对话结束条件
  • 日志记录：保存完整的对话日志用于调试和审计
