分词与 Tokenization

"你好世界"到底被切成了什么？深入理解LLM如何将人类语言转化为可处理的数字序列。

什么是Tokenization？

Tokenization（分词）是LLM处理文本的第一步。它将连续的文本字符串切分为离散的token——模型能理解的最小单位。每个token会被映射为一个唯一的整数ID，再转换为向量表示。

核心洞察：Tokenizer不是简单的"按空格分词"。它会处理多语言、缩写、表情符号，甚至将常见词合并为单个token。同一个词在不同tokenizer下可能被切成不同数量的token。

主流分词方案

BPE（Byte Pair Encoding）

GPT系列使用的分词方案。从字节对开始，逐步合并最常见的相邻token对，直到达到目标词表大小。

  • 优势：能处理未见过的词（通过子词组合）
  • 词表大小：GPT-2约5万，GPT-4约10万
  • 中文处理：中文字通常被拆为单字或常见双字组合

WordPiece

BERT使用的方案。与BPE类似，但合并策略基于似然比而非频率。

SentencePiece

将文本视为原始字节序列，不需要预分词。支持多语言统一词表。

tiktoken（OpenAI）

GPT-4使用的快速分词器，BPE的优化实现。Python和Rust实现。

代码示例

Python · Tokenization对比 
from transformers import AutoTokenizer
import tiktoken

text = "AgentForge是最好的学习平台，让我们开始吧！"

# 1. GPT-2 BPE
gpt2_tokenizer = AutoTokenizer.from_pretrained("gpt2")
gpt2_tokens = gpt2_tokenizer.encode(text)
print(f"GPT-2: {len(gpt2_tokens)} tokens")
print(f"解码: {[gpt2_tokenizer.decode([t]) for t in gpt2_tokens]}")

# 2. Claude的cl100k_base
enc = tiktoken.get_encoding("cl100k_base")
claude_tokens = enc.encode(text)
print(f"Claude: {len(claude_tokens)} tokens")
print(f"解码: {[enc.decode([t]) for t in claude_tokens]}")

# 3. 中文BERT
bert_tokenizer = AutoTokenizer.from_pretrained("bert-base-chinese")
bert_tokens = bert_tokenizer.encode(text)
print(f"BERT中文: {len(bert_tokens)} tokens")
print(f"解码: {bert_tokenizer.convert_ids_to_tokens(bert_tokens)}")

# 输出示例：
# GPT-2: 18 tokens   (英文切分更细，中文按字切)
# Claude: 14 tokens  (对中文更友好)
# BERT中文: 16 tokens (中文按字/词切分)

Token数量对成本的影响

Token数量直接决定了API调用成本和上下文窗口限制：

  • GPT-4o：128K context，~$2.50/1M input tokens
  • Claude 3.5：200K context，~$3/1M input tokens
  • 同样一段中文，不同tokenizer可能差出30%-50%的token数量
# Token成本计算示例
text = "请帮我分析一下2024年AI行业的发展趋势..."
tokens = enc.encode(text)
cost_per_1k = 0.003  # $3/1M tokens
cost = len(tokens) / 1000 * cost_per_1k
print(f"这段文本: {len(tokens)} tokens, 成本: ${cost:.6f}")
# 若选择更高效的prompt措辞，可能节省30%的token

最佳实践

  • 选择合适tokenizer：中文场景优先用支持中文的tokenizer
  • 压缩prompt：同样的意思，不同的措辞可能差几倍token
  • 监控token消耗：生产环境必须监控input/output token数量
  • 避免token浪费：不要在prompt中重复系统指令
  • 中文优化：cl100k_base对中文比GPT-2 tokenizer友好得多
