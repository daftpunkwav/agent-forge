01 / 安全风险

安全关键基础设施已经存在，但浏览器会话与 LLM 不可信内容仍构成最重要的信任边界问题。

CRITICALSEC-01 · Token 存于 localStorage

事实：apps/web/src/lib/apiToken.ts:3-22 读写 access/refresh token；refresh 约 7 天。

影响：任意 XSS 可读取 refresh 并持续换取 access。可信度：高。

建议：refresh 迁移 HttpOnly/Secure/SameSite cookie；access 仅内存保存，并补 Origin/CSRF 负向测试。

HIGHSEC-02 · Tool Observation 未标不可信

事实：apps/api/src/lib/llm/tools/toolLoop.ts 将文章工具结果直接拼回 user message。

影响：半信任文章内容可进行 prompt injection；不是 RCE，但可影响后续模型行为。可信度：高。

建议：结构化封装、长度限制、字段白名单与恶意内容回归测试。

HIGHSEC-03 · BYOK DNS rebinding 窗口

事实：byokUrlPolicy.ts 做 hostname/IP 文本策略，调用前未见 DNS 解析后再次校验。

影响：特制 DNS 可能把请求导向内网或 metadata；本次未做真实利用验证。可信度：中高。

建议：解析 A/AAAA、校验所有地址、锁定连接目标并重新校验重定向。

HIGHSEC-04/05/06 · 配置、成本与提权审计

生产错误脱敏依赖显式 NODE_ENV；tool-loop 与普通 Agent 共用 IP 限流且无用户预算；审批提权缺少完整 actor/subject 审计记录。分别见 errorHandler.ts、app.ts、applications.ts。

已做好的护栏：bcrypt、refresh hash+旋转、AES-256-GCM BYOK、Helmet/CORS、Zod、SSE abort、LLM 错误脱敏、DOMPurify 与核心安全测试。

02 / 架构与耦合

边界清晰，但最复杂的交互集中在少数巨型文件中。建议做“流程抽取”，避免无目标的全栈分层重写。

HIGHARC-01/02 · 两个高密度核心文件

apps/api/src/routes/agent.ts 约 722 行；apps/web/src/components/agent/AgentFloat.tsx 约 914 行。前者混合 SSE 生命周期与业务编排，后者混合 HoverTip、AgentPanel、timer/ref、节流与缓存。

建议：先补行为测试，再抽 SSE runner、HoverTip/AgentPanel 与 hooks，保持现有视觉。

MEDIUMARC-03/04 · 重复与契约漂移

SSE 流控、Provider URL/JSON fallback 多处近似；shared 已有类型但前端仍有手写 Principal 与 Record<string, unknown>。建议提取小型纯函数并收敛共享 DTO。

可保持的取舍：当前 CRUD fat-handler、SQLite 开发默认、prompt-based tool-loop 均有明确边界或文档说明，不应仅因“不是某种架构风格”就重写。

03 / 前端现代化

HIGHWEB-01 · 首屏未分包

路由页面静态 import；构建实际产生 542.31 kB 主 JS（gzip 166.55 kB），Vite 报 chunk >500 kB warning。建议按路由动态 import + Suspense。

HIGHWEB-02 · 无 ErrorBoundary

未发现 ErrorBoundary/componentDidCatch。渲染异常可能白屏。建议在 AppShell/Router 顶层提供不泄露内部错误的恢复 UI。

MEDIUMWEB-03/04/05 · 守卫、lint 与前端测试

多个页面重复内联 role 判断；lint 通过但有 8 条 warning；未见前端单测与完整 E2E。建议统一守卫、清理 warning、先测纯逻辑再加最小用户旅程。

06 / 建议路线图

  1. 0–2 天：HttpOnly refresh、Observation 隔离、JWT 算法白名单、日志 redact、tool 用户级预算。
  2. 1–2 周：路由分包、ErrorBoundary、统一 RequireRole、提权审计、CRUD/RBAC 集成测试、领域大小限制、graceful shutdown。
  3. 2–4 周：抽公共 SSE/Provider helpers、拆 AgentFloat、补齐或标注 Responses 降级、指标与 shared DTO 收敛、遗留治理。

不建议一次性架构重写；每步都应有回归测试与可度量验收标准。
