02 / R2 增量发现（27 条）

R2-01 · Critical · 无 graceful shutdown 与 Prisma 关闭

CRITICALAPI 进程无 SIGTERM/SIGINT 与 Prisma 关闭钩子

事实：index.ts:1-10 仅 app.listen；prisma.ts:1-13 单例无 beforeExit；grep 进程信号命中 0。

影响：K8s rolling update 30s 窗口内 Prisma 残留、活跃 SSE 不通知、Provider 请求挂起直到 SIGKILL；unhandledRejection/uncaughtException 缺日志。

建议：server.close + drainActiveStreams + prisma.$disconnect，超时强制退出；注册 unhandled 钩子。

High · R2-02 ~ R2-09

HIGHR2-02 · .npmrc production=false 影响生产镜像

事实：.npmrc:1-2 + API devDeps 含 prisma/vitest/tsx/@types/*/oxlint；多个 npm 子进程输出 npm warn config production，证明 production=false 被实际应用。

建议：Dockerfile 显式 npm config set production=true && npm ci --omit=dev；或 .npmrc 用 [env] 分组。

HIGHR2-03 · CI 缺 lint/audit/Node 锁/最小权限

事实：ci.yml:1-29 仅 build/test；setup-node node-version: '20' 与 engines.node >= 20.3 不一致；无 permissions/concurrency/Dependabot/SBOM。

建议：加 lint/audit/Trivy/Dependabot；node-version-file: .nvmrc 锁 20.18.x；最小权限 + 并发取消。

HIGHR2-04 · BYOK fetch 默认 follow redirect

事实：三个 adapter fetch(url, {...})；grep "redirect:" 0 命中——Node 18+ fetch 默认 redirect: 'follow'。配合 R1 hostname 策略，3xx 跳到 metadata/内网将完全无防护。

建议：统一 redirect: 'manual'，跳转后重走 assertSafeByokBaseUrl；请求前 dns.lookup 校验每个 IP。

HIGHR2-05 · AuthorApplication 缺 reviewerId 与审计字段

事实：schema.prisma:81-100 无 reviewerId；applications.ts:102-121 不写 audit 字段；与 Annotation.reviewer 未对齐。

建议：加 reviewerId String? + 反向 relation；引入独立 AuditEvent 表 + Pino audit: namespace。

HIGHR2-06 · HttpOnly 迁移前需先实现 CSRF

事实：app.ts:24-31 cors({credentials:true}) 显式允许凭据；无 Origin 校验、无 CSRF token；grep csrf|sameSite 0 命中。

建议：落地 cookie 化前先实现 Origin 头白名单 + 双重提交 cookie + SameSite=Lax，迁移文档将 CSRF 列为前置条件。

HIGHR2-07 · User.preferences JSON 写竞争

事实：schema.prisma:29 整块 JSON；auth.ts:160-176/settings.ts:95-162 read-modify-write，无事务/无锁/无版本号。

建议：短期拆列或乐观锁；中期 PG 后用 jsonb_set；至少在写入前 findUnique + 冲突重试 1 次。

HIGHR2-08 · 无 metrics/tracing；Pino redact 缺位

事实：grep prometheus|opentelemetry|metrics|tracing 0；logger.ts 无 redact；providerHttp.ts diagnostic.raw 是上游 500B 原文；req.originalUrl 含 query 入日志。

建议：Pino redact 全量关键路径；diagnostic.raw 改 hash+截断；prom-client + OTel SDK 串 traceparent 到 SSE 帧。

HIGHR2-09 · SQLite → PG contains 大小写敏感 + 无 GIN 索引

事实：articles.ts:100-105、domains.ts:96-100 用 contains；PG LIKE/Prisma contains 默认大小写敏感；docs/operations/postgres.md 未声明。

建议：切 PG 后用 mode: 'insensitive'；引入 pg_trgm + GIN 索引；文档增补章节。

Medium · R2-10 ~ R2-23

MEDIUMR2-10 · SSE 无 keep-alive comment 与活动连接追踪

sse.ts:1-33 无 : ping、无连接集合；routes/agent.ts 在 req.on('close') 之外不发送心跳；客户端 28s 超时只 abort 不重连。建议每 15-20s 写心跳、维护 Set<Response> 集合；前端加重试预算。

MEDIUMR2-11 · 四类模块级 Map/let 多实例分裂

providers.ts:33-86、agentConversation.ts:22-35、articles.ts:33-48、tools/registry.ts——前三者多实例分裂。整理 in-process state audit；阅读量合并；清理 CronJob 化；Provider 热更。

MEDIUMR2-12 · Prisma 连接池/helmet/Node 版本脱节

prisma.ts 无 connection_limit；helmet() 默认无 CSP/HSTS；ci.yml node-version: '20' 与 engines >=20.3 不一致；index.html 走 Google Fonts CDN。补 URL 显式、Helmet CSP/HSTS、.nvmrc 锁 20.18.x、字体本地化。

MEDIUMR2-13 · 数据库写入时区/索引/软删语义

业务时间在应用层 new Date()；applications 列表无 @@index([createdAt])；Topic/Annotation/Article/Application 软删语义不一。时区统一 UTC、补高频索引、文档化软删/工作流状态。

MEDIUMR2-14 · SSE 单飞缺失；限流 store 内存化

routes/agent.ts:209-241 早停仅本实例；app.ts:55-77 默认内存 store 多实例失效。DB 软锁 / Redis SETNX；rate-limit-redis 替换。

MEDIUMR2-15 · 聊天历史累积、搜索 contains、JSON 写热点

每次 chat 拉 12 条 + loadUserContext 无 LRU；getHoverCache 命中即 updateMany hits+1；搜索 contains 全文扫；markdown 字段无 .max()。LRU 60s、批量 flush、PG pg_trgm + GIN、markdown max 200_000。

MEDIUMR2-16 · SSE 中间事件日志与 trace 串联

tool loop 仅结束/超限打点；requestId 8 hex 32 bit 生日碰撞；LLM 调用日志不串 requestId；agentOrchestrator.llmError 未透传。加低频心跳日志；requestId 16 hex + AsyncLocalStorage；或直接 OTel trace context。

MEDIUMR2-17 · 缺 Dockerfile / Compose 无 api/web / 无反代

无 Dockerfile、docker-compose.yml 只 Postgres；apps/web/package.json 无 start 脚本。补 Dockerfile 多阶段、.dockerignore、Compose 升级为含 api/web/proxy、提供 Caddyfile。

MEDIUMR2-18 · /health 不感知依赖

浅 /health。补 /healthz（浅 liveness）+ /readyz（深 readiness，SELECT 1 + provider 列表）。

MEDIUMR2-19 · 审计日志缺失

审批//logout 等无审计事件。引入 AuditEvent 表（append-only）+ Pino audit: namespace。

MEDIUMR2-20 · 前端无 error sink

前端 catch 后只 throw ApiError，无上报。最小化 error sink：window.onerror + unhandledrejection → /api/v1/telemetry/client-errors，与 OTel trace context 整合。

MEDIUMR2-21 · CI 缺 lockfile/缓存/Dependabot

显式 cache-dependency-path: package-lock.json；加 Dependabot version + security updates；OSS-license-check + SBOM。

MEDIUMR2-22 · 缺 RUNBOOK / 故障排查

建 docs/operations/：incident-llm / incident-db / deploy-checklist / shutdown-drill。

MEDIUMR2-23 · 缺性能基线

为 /health、/agent/explain、/auth/login 写 k6 基线；CI 引入性能回归门槛。

Low · R2-24 ~ R2-27

LOWR2-24 · Article slug PATCH 缺事务兜底

PATCH slug 走 findUnique 后 update，并发可能 P2002 转 500。包 prisma.$transaction，外层 catch P2002 转 409。

LOWR2-25 · Hover cache 截断与 key 不一致

cacheKey 用 topic.slice(0, 400)，写库 topic.slice(0, 200)，可能同 key 异查询。抽 cacheTopicFor(topic) 同源同长；写库超长仅记日志丢弃。

LOWR2-26 · 前端 ARIA 语义缺失

视图/筛选按钮缺 aria-pressed / aria-current；统计卡用 <div>；模态用 window.confirm。抽 <ToggleButton>/<SelectionChips>；统计卡 <dl>；按钮组 role="group" aria-label。

LOWR2-27 · articles animations PATCH 缺事务；Topic status 语义未集中

三个 query 顺序执行无事务；Topic 状态分支膨胀。包事务；Topic.status 收紧为 enum 或 assertTopicCanReply。
