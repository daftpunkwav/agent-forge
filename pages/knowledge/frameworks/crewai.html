CrewAI：角色扮演Agent框架

CrewAI 是最易上手的多Agent框架，采用"角色扮演"模式——每个Agent有名字、角色、目标和工具，像管理一个团队一样管理Agent。

角色驱动的Agent

CrewAI 的核心设计哲学是"像管理人类团队一样管理AI"。你定义一个Crew（团队），给每个Agent分配角色（Role）、目标（Goal）和背景故事（Backstory），然后CrewManager会自动协调Agent完成复杂任务。

与AutoGen的"对话驱动"不同，CrewAI是"任务驱动"——你定义"要做什么"，而不是"怎么对话"。

核心洞察：给Agent一个明确的角色，能显著提升输出质量和方向一致性。人类如此，Agent亦如此。

核心概念

Agent

具备以下属性的执行单元：

  • Role：角色名称（如"数据分析师"）
  • Goal：核心目标
  • Backstory：背景故事（用于丰富System Prompt）
  • Tools：可使用的工具列表
  • LLM：使用的语言模型

Task

需要完成的具体任务。每个Task有描述、期望输出、分配给特定的Agent。

Crew

Agent的团队。Manager（通常是LLM）协调Agent之间的任务分配和执行顺序。

代码示例

Python · CrewAI 多Agent团队 
from crewai import Agent, Task, Crew, Process
from crewai_tools import SerperDevTool, ScrapeWebsiteTool

# 1. 定义Agent
researcher = Agent(
    role="高级研究员",
    goal="发现和收集关于{TOPIC}的最新技术信息",
    backstory="你是一位经验丰富的技术研究员，擅长在互联网上"
             "搜索和整理信息。你的报告总是全面且准确。",
    tools=[SerperDevTool(), ScrapeWebsiteTool()],
    verbose=True,
)

writer = Agent(
    role="技术作家",
    goal="将研究结果转化为清晰易懂的技术文章",
    backstory="你是一位优秀的技术作者，擅长将复杂的概念"
              "转化为清晰、结构化的文章。",
    verbose=True,
)

# 2. 定义Task
research_task = Task(
    description="研究{topic}的最新发展，找到5个关键趋势和3个重要工具",
    expected_output="一份结构化的研究报告，包含趋势分析和工具对比",
    agent=researcher,
)

writing_task = Task(
    description="基于研究报告撰写一篇800字的技术博客文章",
    expected_output="一篇完整的技术博客文章，包含标题、引言、正文和总结",
    agent=writer,
)

# 3. 创建Crew并执行
crew = Crew(
    agents=[researcher, writer],
    tasks=[research_task, writing_task],
    process=Process.sequential,  # 顺序执行
    verbose=True,
)

result = crew.kickoff(inputs={"topic": "2024年AI Agent发展"})
print(result)

执行流程

  • Sequential：任务按顺序执行，前一个的输出作为后一个的输入
  • Hierarchical：Manager Agent动态分配和排序任务
  • Consensus：多个Agent对同一任务给出结果后综合

框架对比

  • vs LangChain：CrewAI更高层；LangChain更灵活
  • vs AutoGen：CrewAI任务驱动；AutoGen对话驱动
  • 上手难度：CrewAI < AutoGen < LangChain

最佳实践

  • 角色要具体："数据分析师"比"AI助手"好
  • Backstory要认真写：背景故事直接影响Agent行为
  • 工具要匹配角色：不要让写作Agent调用代码执行工具
  • 从小团队开始：2-3个Agent足够，更多时管理复杂度飙升
