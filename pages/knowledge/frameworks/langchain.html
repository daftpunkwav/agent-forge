LangChain：Agent开发框架

LangChain 是最流行的LLM应用开发框架，提供了Agent、Chain、Memory、Tool等丰富的模块，是Agent开发的事实标准起点。

LangChain 是什么？

LangChain 是一个开源框架，旨在简化LLM应用的开发。它提供了一套标准化的抽象和工具，让开发者可以快速构建复杂的AI应用，而不需要处理底层的API调用、数据格式转换等细节。

核心洞察：LangChain 的本质是"LLM应用的胶水层"——连接模型、数据、工具和记忆。

核心概念

LLM / ChatModel

统一的模型接口。无论底层是OpenAI、Anthropic还是本地模型，通过LangChain的接口可以无缝切换。

PromptTemplate

可复用的Prompt模板。支持变量插值、部分填充，可以像函数一样被调用。

Chain

将多个操作链接在一起。LLMChain = Prompt + LLM + OutputParser，是最基本的组合模式。

Agent

拥有推理能力和工具调用能力的自主实体。Agent根据输入动态决定下一步行动，是LangChain最强大的模块。

Tool

Agent可以调用的功能。LangChain内置了大量工具，也支持自定义工具。

Memory

对话记忆管理。LangChain提供了多种记忆后端——内存、文件、向量数据库。

Retriever

文档检索器。LangChain提供了多种向量存储和检索策略，是RAG应用的核心。

代码示例

Python · LangChain Agent 
from langchain.agents import create_agent, AgentExecutor
from langchain.tools import Tool
from langchain_anthropic import ChatAnthropic

# 1. 初始化模型
llm = ChatAnthropic(model="claude-sonnet-4-20250514")

# 2. 定义工具
def search(query: str) -> str:
    """搜索网络获取信息"""
    return web_search(query)

def calculate(expr: str) -> str:
    """计算数学表达式"""
    return str(eval(expr))

tools = [
    Tool(name="Search", func=search, description="搜索网络"),
    Tool(name="Calc", func=calculate, description="数学计算"),
]

# 3. 创建Agent
agent = create_agent(
    llm=llm,
    tools=tools,
    system_prompt="你是一个有用的助手，使用工具回答用户问题。"
)

# 4. 执行
executor = AgentExecutor(agent=agent, tools=tools)
result = executor.invoke({"input": "上海的房价和北京的房价各是多少？"})
print(result["output"])

LangChain v0.3+ 架构

  • LangChain Core：LCEL（LangChain Expression Language），声明式链式组合
  • LangGraph：图结构Agent编排，支持循环、状态管理
  • LangSmith：可观测性平台（调试、评估、监控）
  • LangServe：部署服务

框架对比

  • vs AutoGen：LangChain更灵活但更复杂；AutoGen更简单但定制性低
  • vs LlamaIndex：LangChain更全面；LlamaIndex专注RAG
  • vs CrewAI：LangChain底层；CrewAI高层封装

最佳实践

  • 优先用LCEL：声明式写法更易读、更易调试
  • LangGraph做复杂Agent：需要状态管理和循环时用LangGraph
  • 开启LangSmith追踪：调试Agent行为必须用
  • 模块化工具：每个工具只做一件事
