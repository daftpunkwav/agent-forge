MCP：模型上下文协议

Model Context Protocol（MCP）是 Anthropic 推出的开放协议，标准化了 AI 模型与外部数据源、工具之间的交互方式。它是 Agent 生态的"USB接口"。

MCP 解决了什么问题？

在使用 LLM 构建 Agent 时，一个核心挑战是：如何让模型安全、标准化地访问外部资源和工具？每个工具可能有不同的 API 格式、认证方式、返回结构。MCP 提供了一个统一的抽象层。

想象一下 USB 接口——不管是什么设备，只要插上就能用。MCP 就是 Agent 生态中的"USB接口"——一个 MCP Client（如 Claude Desktop）可以连接任何 MCP Server，就像插入U盘一样简单。

核心洞察：MCP 将"模型能做什么"从硬编码变成可插拔。开发者可以像搭积木一样组合工具，而模型端无需关心具体实现。

MCP 架构

MCP 采用 Client-Server 架构，包含三个核心概念：

Resources（资源）

Server 提供的数据源，供 Client 读取。类似于"文件系统"——可以是文件内容、数据库记录、API响应等。Resources 是被动的——Client 读取，Server 提供。

Tools（工具）

Server 提供的能力函数，供 Client 调用。类似于"API端点"——模型可以调用它们来执行操作（搜索、计算、写入数据等）。Tools 是主动的——Client 请求执行，Server 执行并返回结果。

Prompts（提示模板）

Server 提供的预定义提示模板，帮助模型更好地完成任务。例如"总结这段文本"的标准格式模板。

快速上手

TypeScript · MCP Server 
import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";

const server = new McpServer({ name: "weather", version: "1.0.0" });

// 定义一个工具
server.tool("get_weather", { city: z.string() }, async ({ city }) => {
  const data = await fetchWeather(city);
  return {
    content: [{ type: "text", text: JSON.stringify(data) }]
  };
});

// 定义一个资源
server.resource("weather-report", "weather://report/{city}", async (uri) => {
  const city = uri.pathname;
  const data = await fetchWeather(city);
  return { contents: [{ uri, text: JSON.stringify(data) }] };
});

生态现状

  • Claude Desktop：原生支持 MCP，可通过配置连接多个 Server。
  • Cursor IDE：支持 MCP 工具集成。
  • LangChain：通过 langchain-mcp-adapters 支持 MCP。
  • 社区 Server：文件系统、数据库、GitHub、Slack 等已有大量社区实现。
