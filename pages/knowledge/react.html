ReAct：推理与行动的交替循环

ReAct（Reason + Act）是Agent最核心的推理模式之一。本文将通过交互式动画，让你直观理解Agent如何在"思考"和"行动"之间交替循环，最终解决问题。

什么是ReAct？

ReAct 是由 Google Research 和 Princeton University 在 2022 年提出的推理框架。它的核心思想非常简洁：让Agent交替进行"推理(Reasoning)"和"行动(Action)"，而不是像传统Chain-of-Thought那样只做纯文本推理。

想象一下你解决一个复杂问题时：你不会一次性想完所有步骤然后行动——你会想一步、做一步、看看结果、再想下一步。ReAct 就是让 LLM 模拟这种人类式的解决问题方式。

核心洞察：将推理过程与行动过程交织在一起，让每一步推理都能基于实际观察结果进行调整，大幅提高了复杂任务的解决准确率。

REACT 推理与行动交替循环

核心原理

ReAct 的工作流程可以用以下循环来描述：

Thought（思考）

在每一步，Agent首先进行推理，思考当前状态和下一步该做什么。这个推理过程是显式的——它会以文本形式输出，让我们能看到Agent的"想法"。

Action（行动）

基于推理结果，Agent选择一个具体的行动。行动通常是调用一个工具（如搜索、计算、读取文件等）。Action包含两个部分：行动名称和行动参数。

Observation（观察）

行动执行后，Agent会收到一个观察结果——工具返回的数据。这个结果成为下一步推理的输入，驱动循环继续。

Question → Thought → Action → Observation ↻

循环直到得到最终 Answer

代码示例

下面是一个使用LangChain实现ReAct Agent的示例：

Python · LangChain 
from langchain.agents import initialize_agent, AgentType
from langchain.llms import OpenAI
from langchain.tools import Tool

# 定义工具
tools = [
    Tool(
        name="搜索",
        func=lambda q: search_engine(q),
        description="用于搜索网络信息"
    ),
    Tool(
        name="计算器",
        func=lambda expr: eval(expr),
        description="用于数学计算"
    )
]

# 初始化 ReAct Agent
llm = OpenAI(temperature=0)
agent = initialize_agent(
    tools=tools,
    llm=llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
    verbose=True  # 输出完整的 Thought-Action-Observation 循环
)

# 运行
result = agent.run("2024年巴黎奥运会中国获得多少金牌？")
# 输出会包含完整的 ReAct 循环：
# Thought: 我需要搜索2024年巴黎奥运会的信息...
# Action: 搜索
# Action Input: 2024年巴黎奥运会中国金牌数
# Observation: 中国获得40枚金牌...
# Thought: 基于搜索结果，答案是40枚...
# Final Answer: 中国在2024年巴黎奥运会上获得了40枚金牌。

ReAct vs CoT

理解ReAct最好的方式是将其与CoT（Chain-of-Thought）对比：

特性 CoT ReAct
推理方式 纯文本推理链 推理 + 行动交替
外部交互 不支持 支持工具调用
可解释性 高（纯文本） 高（带行动记录）
适用场景 数学、逻辑推理 需要工具的复杂任务

最佳实践

  • 工具描述要清晰：Agent依赖工具描述来选择行动，模糊的描述会导致选错工具。
  • 限制循环步数：设置最大步数（如10步）防止Agent陷入无限循环。
  • 正则化Observation：过长的工具返回结果会消耗token，需要截断或摘要。
  • 使用Few-shot提示：在System Prompt中提供ReAct格式的示例，引导正确的输出格式。
  • 错误处理：工具调用可能失败，需要在Observation中明确返回错误信息，让Agent能自我修正。
