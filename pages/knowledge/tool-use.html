工具调用（Function Calling）

工具调用让LLM能够执行实际操作——搜索网页、操作数据库、调用API。这是从"聊天机器人"到"Agent"的关键一步。

从"说"到"做"

传统LLM只能生成文本——它"说"得再好，也无法真正帮你查天气、发邮件、操作数据库。工具调用（Function Calling）让LLM能够：

  • 选择合适的工具
  • 格式化正确的参数
  • 接收工具的执行结果
  • 基于结果继续推理或给出最终答案
核心洞察：工具调用不是让LLM"学会"使用工具，而是让LLM学会"描述"如何使用工具——实际的执行由宿主程序完成。

工作机制

工具调用的标准流程：

  1. 定义工具：开发者向LLM描述可用的工具（名称、参数schema、用途）
  2. LLM决策：模型根据用户输入，判断是否需要调用工具，以及调用哪个工具
  3. 参数生成：模型输出结构化的工具调用请求（函数名 + 参数JSON）
  4. 宿主执行：宿主程序接收请求，实际执行工具，返回结果
  5. 结果注入：工具结果作为新消息注入对话，模型继续推理

代码示例

Python · OpenAI Function Calling 
from openai import OpenAI

client = OpenAI()

# 1. 定义工具
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "获取指定城市的当前天气",
            "parameters": {
                "type": "object",
                "properties": {
                    "city": {
                        "type": "string",
                        "description": "城市名称，如北京、上海"
                    },
                    "unit": {
                        "type": "string",
                        "enum": ["celsius", "fahrenheit"],
                        "description": "温度单位"
                    }
                },
                "required": ["city"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "search_web",
            "description": "搜索网络获取最新信息",
            "parameters": {
                "type": "object",
                "properties": {
                    "query": {
                        "type": "string",
                        "description": "搜索关键词"
                    }
                },
                "required": ["query"]
            }
        }
    }
]

# 2. 发起请求
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "北京今天天气怎么样？"}],
    tools=tools,
)

# 3. 处理工具调用
message = response.choices[0].message
if message.tool_calls:
    for tool_call in message.tool_calls:
        function_name = tool_call.function.name
        function_args = json.loads(tool_call.function.arguments)

        # 执行实际工具
        if function_name == "get_weather":
            result = get_weather_api(function_args["city"])

        # 将结果回传给模型
        response = client.chat.completions.create(
            model="gpt-4o",
            messages=[...message, {
                "role": "tool",
                "tool_call_id": tool_call.id,
                "content": str(result)
            }],
            tools=tools,
        )

并行工具调用

现代LLM支持在单次响应中并行调用多个工具。当用户请求需要多个独立的信息源时，这能显著降低延迟。

最佳实践

  • 工具描述要精确：描述越清晰，模型选对工具的概率越高
  • 参数Schema严格：使用明确的类型和枚举值，减少模型猜测
  • 错误处理：工具执行可能失败，返回清晰的错误信息
  • 超时设置：为每个工具设置合理的超时，防止卡死
  • 结果截断：大结果截断到合理大小，避免撑爆context
  • 权限控制：敏感工具需要额外的权限验证

框架支持

  • LangChain：Agent + Tools 模块，支持多种LLM后端
  • OpenAI API：原生function calling
  • Anthropic API：tool_use block类型
  • LlamaIndex：ToolSpec封装
  • MCP：标准化工具协议
