LLM 基础：大语言模型入门

理解大语言模型的基本原理——从Transformer架构到训练范式，为Agent开发打下坚实的理论基础。

什么是大语言模型？

大语言模型（Large Language Model, LLM）是基于深度学习的大规模文本生成模型。通过在海量文本数据上进行预训练，LLM学会了语言的统计规律，获得了理解、生成和推理文本的能力。

当前主流的LLM都基于Transformer架构，采用"预测下一个token"的训练目标。GPT系列、Claude、Gemini、LLaMA等都是这一范式的代表。

核心洞察：LLM的本质是一个"超级补全器"——给定一段文本，它预测最可能的下一个词。正是这个简单目标，涌现出了惊人的推理和生成能力。

核心架构

LLM建立在Transformer架构之上，关键组件包括：

  • Tokenization：将文本拆分为token序列
  • Embedding：将token映射为向量表示
  • Self-Attention：让每个token"看到"序列中的其他token
  • Feed-Forward：对每个位置的表示进行非线性变换
  • Layer Normalization：稳定训练过程
  • Output Head：预测下一个token的概率分布

训练范式

预训练（Pre-training）

在海量无标注文本上，使用"下一个token预测"目标训练基础模型。这是最昂贵的阶段。

微调（Fine-tuning）

在特定任务的有标注数据上继续训练，使模型适应特定领域或格式。

RLHF / Alignment

通过人类反馈强化学习，让模型输出更符合人类偏好——更安全、更有用、更诚实。

核心能力

  • In-context Learning：通过示例学习新任务，无需更新权重
  • Chain-of-Thought：逐步推理解决复杂问题
  • Instruction Following：精确遵循自然语言指令
  • Code Generation：编写、理解、调试代码

局限

  • 幻觉：自信地生成不准确的信息
  • 上下文窗口限制：能同时处理的信息量有限
  • 数学推理：复杂计算容易出错
  • 知识截止：训练数据截止后无法学习新信息
  • 不确定性量化：不知道"自己不知道什么"
