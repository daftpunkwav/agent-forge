Transformer 架构详解

深入理解Transformer——当今所有LLM的基石架构。从Self-Attention到位置编码，逐层剖析。

Attention Is All You Need

2017年，Google发表了一篇改变整个AI领域的论文。他们证明：仅使用注意力机制，就足以构建最先进的语言模型，无需循环或卷积。

核心洞察：Self-Attention让序列中的每个位置都能直接"看到"所有其他位置。这解决了RNN的顺序瓶颈，也让模型能直接捕捉长距离依赖。

架构总览

Transformer由Encoder（编码器）和Decoder（解码器）组成。GPT系列只使用Decoder，BERT只使用Encoder。

Tokenization 与 Embedding

from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("gpt2")
text = "AgentForge 是最好的学习平台"
tokens = tokenizer.encode(text)
decoded = [tokenizer.decode([t]) for t in tokens]

print(f"原始文本: {text}")
print(f"Tokens: {tokens}")
print(f"解码: {decoded}")
print(f"Token数量: {len(tokens)}")
# 输出可能类似: ['Agent', 'For', 'ge', ' 是', '最好', '的', '学习', '平台']

Self-Attention 机制

Self-Attention是Transformer的核心。它的计算过程：

  1. 将每个token映射为Query(Q)、Key(K)、Value(V)三个向量
  2. 计算Q与所有K的点积，得到注意力分数
  3. 用softmax归一化分数
  4. 加权求和V，得到每个位置的输出表示

Multi-Head Attention

将Q、K、V拆分为多个"头"，每个头独立计算注意力，最后拼接。这让模型能同时关注不同层面的语义关系。

位置编码

Transformer没有内置的顺序信息。位置编码（Positional Encoding）为每个位置添加了位置信息，让模型知道token的先后顺序。

前馈网络与残差连接

每个Transformer层包含：

  • Multi-Head Self-Attention
  • 残差连接 + LayerNorm
  • 位置前馈网络（FFN）
  • 残差连接 + LayerNorm

Decoder与GPT

GPT系列使用Decoder-only架构。每个token只能看到前面的token（Causal Attention），所以它是一次只生成一个词的"自回归"模型。
